# Rockford V2B Lineup Hub (phase 1 : socle 2D)
1. Supabase : cree un projet, ouvre SQL Editor, colle `supabase/schema.sql`, clique Run.
2. Copie `.env.example` en `.env.local` et remplis les 2 valeurs (Project Settings > API).
3. Mets ton plan de la map dans `public/map/rockford-v2b.png`.
4. `npm install` puis `npm run dev` et ouvre http://localhost:3000
